Giới Thiệu Về Nguyễn Thị Mỹ Hương: Hành Trình Lập Trình

Học Vấn & Quá Trình Đào Tạo

Tôi là Nguyễn Thị Mỹ Hương, hiện là sinh viên năm ba Khoa Công nghệ Thông tin trường Đại học Giao thông vận tải TP.HCM (UTH) (niên khóa 2021 – Hiện tại). Tôi có nền tảng vững vàng về Khoa học Máy tính: Cấu trúc Dữ liệu & Giải thuật (DSA), Lập trình Hướng đối tượng (OOP), Mạng máy tính và Cơ sở Dữ liệu Quan hệ chuẩn 3NF.

Bên cạnh chương trình đào tạo chính quy tại trường UTH, tôi luôn chủ động tự học và nghiên cứu các xu hướng công nghệ mới: tham gia các buổi Tech Talk chuyên sâu, nghiên cứu thiết kế giao diện UI/UX trên Dribbble và Awwwards, và thực hành tạo các hiệu ứng micro-animations mượt mà.

Kỹ Năng Kỹ Thuật Trọng Tâm

  • Frontend: HTML5 (Semantic), CSS3 (Flexbox, CSS Grid, Animations), JavaScript (ES6+, DOM Manipulation), React.js, Tailwind CSS, Bootstrap 5.
  • Backend: Java Core (vững OOP), Spring Boot, Node.js & Express, thiết kế RESTful APIs chuẩn quốc tế, tích hợp GitHub Webhooks.
  • Cơ sở dữ liệu: MySQL (chuẩn hóa 3NF), Microsoft SQL Server.
  • Công cụ & Quản lý mã nguồn: Git, GitHub, Postman, Visual Studio Code, IntelliJ IDEA, Figma, MySQL Workbench.

Mục Tiêu Nghề Nghiệp

Mục tiêu ngắn hạn (1 - 2 năm): Trở thành Thực tập sinh (Intern) / Fresher Web Developer tại các doanh nghiệp công nghệ, hòa nhập quy trình chuẩn Agile/Scrum, văn hóa Code Review và phát triển chuyên sâu hệ sinh thái React.js & Spring Boot.

Mục tiêu dài hạn (3 - 5 năm): Trở thành Software Engineer độc lập, làm chủ kiến trúc mã nguồn sạch (Clean Architecture), kiểm thử tự động (Unit/Integration Test) và tối ưu hóa ứng dụng quy mô lớn.

Phòng Trưng Bày: Các Dự Án Tiêu Biểu

Dưới đây là các dự án phần mềm thực tế được xây dựng bởi Nguyễn Thị Mỹ Hương:

1. Hệ Thống Quản Lý Jira và GitHub

Thể loại: Backend & Tự động hóa CI/CD Workflow.
Công nghệ: Java, Spring Boot, GitHub Webhooks, Jira REST API, Postman, Git.
Điểm nổi bật: Xây dựng endpoint RESTful API bảo mật tiếp nhận payload Webhook từ GitHub, tự động cập nhật trạng thái Task tương ứng trên Jira Cloud (To Do -> In Progress -> Done) khi có Commit hoặc Pull Request, ghi nhận Commit Message, Author, Timestamp trực tiếp vào Jira issue log.

2. ReMarket (Website Mua Bán Đồ Cổ)

Thể loại: E-Commerce Fullstack Web App.
Công nghệ: HTML5, CSS3, JavaScript ES6, Node.js / Express, MySQL, Bootstrap 5.
Điểm nổi bật: Nền tảng thương mại điện tử kết nối cộng đồng sưu tầm cổ vật. Thiết kế CSDL quan hệ MySQL chuẩn 3NF. Giải pháp kỹ thuật cốt lõi: Cơ chế khóa đơn hàng tạm thời (Locking mechanism / Concurrency control) khi thanh toán để giải quyết triệt để bài toán tồn kho sản phẩm "độc bản" (Unique Item - chỉ có 1 sản phẩm duy nhất), tránh đặt trùng.

3. Website Đăng Ký Hội Viên Gym

Thể loại: Frontend Web App (SPA).
Công nghệ: HTML5 Semantic, CSS3 Animation, JavaScript ES6+, LocalStorage API.
Điểm nổi bật: Đăng ký thẻ tập gym, chọn gói tập (Standard, VIP, Platinum) và Huấn luyện viên cá nhân (PT). Xử lý hoàn toàn bằng JavaScript thuần không phụ thuộc thư viện bên ngoài giúp tối ưu tốc độ, đồng bộ và lưu trữ dữ liệu tức thời qua LocalStorage API, validation chặt chẽ thông tin đầu vào.
